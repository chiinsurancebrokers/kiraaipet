# PetsAIHealth (kiraaipet)

Streamlit app (single file `app.py`) for pet parents in Greece: nurse chat → vet report, plus tools
(vitals/breathing, photo, labs, longevity, diary, vets, insurance). Greek-first, English supported.

- UI layer: `petify_ui.py` (CSS + HTML builders), `petify_art.py` (SVG scenes), `pet_longevity.py`, `petscan_component.py`.
- Flow: landing (with sign-in at the end) → profile (4 steps) → Home → nurse chat → report. Router is at the bottom of `app.py`.
- Insurance: only EFG Eurolife “My Happy Pet” programmes; contracted network list is `_EUROLIFE_NETWORK` in `app.py`.
- Local preview: `streamlit run dev/harness.py --server.port 8504`, then `?t=<screen>` (add `&s=N` for intake step,
  `&chat=1|emerg` for a seeded chat, `&ins=1` for a selected Eurolife programme). No AI keys locally.
- Deploys: Railway project “pet ai nurse”; `web-staging` follows branch `design/petify-layout`, `web` follows `main`.
- Brand name is “PetsAIHealth” (no apostrophe; file names stay lowercase).
- Plans: free = 3 symptom checks/month (counted in Supabase `usage_events`, kind `triage_check`); “PetsAIHealth Plus” 4,99€/mo
  (49,99€/yr) unlocks every other service (`PAID_SCREENS`). Entitlement = row in `subscriptions` with plan `plus` (legacy `insurance` also counts).
  Checkout links: env `STRIPE_CHECKOUT_MONTHLY` / `STRIPE_CHECKOUT_YEARLY` (app appends `prefilled_email` + `client_reference_id`).
  Stripe → access: Supabase edge function `stripe-webhook` (source in `supabase/functions/`, signing secret lives in Supabase Vault via `get_stripe_webhook_secret()`) writes `subscriptions`.
  Pets: free = 1 pet, profile locked; Plus = unlimited pets (switch/edit/add on Home). Profiles saved encrypted in `user_pets`. `PLUS_PAYWALL=off` disables gating.
  Harness: `&plus=0|1`, `&used=N` (needs fake SUPABASE env to turn the paywall on).

  Landing: plan cards have the CTAs (`pl_free`/`pl_plus`); the sign-in form appears only after one is pressed (`_login_plan`; Plus → paywall page after login).
  Eurolife waiting period: pet profile stores `policy_start` + `policy_number` (intake step 4 for Plus users, or Insurance screen); `waiting_status()` (45 days) feeds the coverage prompt, policy chat and the banner.
  Stripe return: Payment Links redirect to `<app>/?paid=1` (currently the web-staging URL; repoint both links to `web` when going live). `render_paid_page` re-checks the subscription. Account page (`screen=account`, 👤 in nav): plan, renewal, Stripe Billing Portal (`STRIPE_SECRET_KEY` + `subscriptions.stripe_customer_id`) and log out.
  Billing agent: chat on the Account page (`render_billing_agent`, `_BILLING_SYSTEM`) answers about price/upgrade/invoices/cancel and only *shows* action buttons (Stripe checkout or Stripe portal); it never cancels or charges by itself.
  Webhook events enabled in Stripe: checkout.session.completed, invoice.paid, customer.subscription.updated/deleted, charge.refunded (full refund ends access now). Subscription check is cached 2 min per session. A refund does not cancel the Stripe subscription: cancel it too, or it renews.
  Pet archive (Plus): `pet_records` table (Fernet payload, `expires_at` = +6 months; pg_cron job `purge-pet-records` daily 03:17 UTC + purge on every read). `save_record()` is called after report / lab / photo / vitals; `history_context()` is appended in `petainurse_system()` (nurse, report, recs), the lab analysis and the second opinion. Screen `history` (📁 on Home for Plus); OPT-IN: nothing is stored until the user says yes (pref `history_consent` in `user_prefs`: None=not asked, True, False; consent card on Home + Archive screen); privacy page lists it and the GDPR delete wipes it. Only result *texts* are stored, never files/photos.

  Safety rules (`vet_rules.py`): deterministic floor under the nurse chat. `evaluate(species_key, owner_texts, pet)` checks everything the owner wrote (Greek + English,
  accent-insensitive) against ~103 rules + a dose-aware chocolate calculator, each tied to an MSD Veterinary Manual page (rules with `basis="policy"` come from the nurse prompt and still need vet review).
  Wired in `_send_to_petainurse`: hits are appended to the nurse system prompt as alerts, and a FINAL `[TRIAGE: ...]` verdict below the rule floor is raised (with a one-line note). It never lowers a level and never
  ends the 6-question cycle early. Edit/add rules in `RULES`; run `python3 -I dev/test_vet_rules.py` (196 cases, no deps). Add a regression case for every rule you change.

  Extra layers (`vet_safety.py`, all can only RAISE a level): (2) an LLM fact-extraction call turns the owner's words into facts that are fed to the same rules (skipped when the keyword rules already reach EMERGENCY; cached per message set); (3) if the AI call fails the owner gets `fallback_reply()` (URGENT, or the rule floor), never an error or an all-clear; (4) `profile_hits()` age/condition floors (puppy, senior, diabetes, kidney, heart, rabbit anorexia); (5) `safety_net()` "go now if" list appended to every URGENT/SELF_CARE verdict; (6) `log_event("safety_disagreement", ...)` records codes only (kinds: rules_raised_ai, extraction_or_profile_rescue, ai_failed, ai_only_emergency): review weekly in Railway logs; (7) `vitals_hits()` floors from breaths/min, SpO2, temp, heart rate (policy basis, vet to confirm limits); owner text has `[TRIAGE:]`/`[TOOL:]` lookalikes stripped. Tests: `dev/test_vet_safety.py` (no deps) and `dev/e2e_safety.py` (needs app requirements); both run in `.github/workflows/safety.yml`. MSD pet-owner knowledge (`vet_knowledge.py`): paraphrased owner-level facts per topic (food, household, drugs, plants, snakebite, insecticide, metaldehyde, salt, heat/first aid, bloat, parvo) are appended to the nurse prompt only when the chat mentions the topic, plus a first-aid guardrail (never induce vomiting at home or give human drugs unless a vet says so); rules added from the same pages: snakebite, metaldehyde, poisoned bait, dog flea product on cat, batteries, corrosives, alcohol, OTC/Rx human drugs, severe plants, bread dough, avocado (birds), salt dough, choking, bloody vomit/diarrhoea, parvo, swallowed foreign bodies. Test `dev/test_vet_knowledge.py`.

  Follow-up reminder (`followups.py`, table `followups` in `supabase/migrations/20261025_followups.sql`): opt-in button after an URGENT/SELF_CARE verdict (`_render_followup_offer`, signed-in only) inserts one row (URGENT +6h, SELF_CARE +24h, never 22:00-08:00 Athens); worker `python3 followups.py` sends the due rows via Resend (env `SUPABASE_SERVICE_ROLE_KEY`, `RESEND_API_KEY`, `FOLLOWUP_FROM`, `APP_URL`) and must run every 15-30 min as a Railway cron service; mail holds no symptoms; GDPR delete wipes the rows; test `dev/test_followups.py`.

  Safety hardening (round 3): negation guard (`vet_rules.strip_negated`, exposure rules in `_GUARDED` ignore "did not eat X"; uncertain wording still fires); kill switch env `VET_FLOOR=off` (all rule/profile/vitals/knowledge/safety-net layers; the AI-failure fallback stays on) and `VET_EXTRACT=off` (only the extraction call); extraction runs on `CLAUDE_EXTRACT_MODEL` (default `claude-haiku-5-5`, retried once with the main model if unavailable); small-pet rules for species `other` (guinea pig, hamster, ferret, from MSD all-other-pets); poison hand-off card (`vet_safety.handoff`: call vet/24h clinic + vet finder; only official numbers are the N.E.C.C.A. poisoned-bait line 210 8089271 and animal abuse line 10410, there is NO Greek veterinary poison helpline to cite); code-only event log `safety_events` (migration `20261025_safety_events.sql`, app can insert only) with `python3 safety_events.py --days 7 --alert` (run daily in the cron service; env `SAFETY_ALERT_TO`); one-tap follow-up outcome links (edge function `supabase/functions/followup-outcome`, deploy with verify_jwt=false, secret `FOLLOWUP_SIGNING_SECRET` shared with the worker env, GET shows a confirm button, POST records, mail scanners cannot answer for the user); labelled benchmark `dev/vet_cases.jsonl` + `dev/run_vet_benchmark.py` (seed cases are NOT clinically validated: put a vet name in `reviewed_by` when labelled).

  Real-case check: 8 MSD case studies (`dev/vet_cases.jsonl`, ids M001-M008, `source` = MSD URL, truth = my proposed level, NOT vet-reviewed) were run blind against the rules: 7 of 8 were under-triaged (no floor). Rules ALL-NEURO, CAT-ABDOMEN, DC-GI-PERSISTENT, DC-HEMATURIA, DC-LAME-SEVERE, DC-YOUNG-GI were added (policy basis except DC-LAME-SEVERE). They now pass by construction, so they only guard against regressions; they are not an independent measure.

  Real-case check, batch 2: the MSD sitemap (`sitemaps/veterinary-casestudy.xml`) lists all 34 case studies; 13 more pet cases were added (M009-M021). Blind run: 8 of the 10 cases that needed a rule were missed, plus 1 false alarm (the labour rule fired on "straining to pee"). Rules added: DC-CANT-WALK, DC-NOSEBLEED, DC-JAUNDICE, DC-ANOREXIA-LONG, DC-WOUND-NONHEAL, DC-LUMP-OPEN, DOG-URINARY-STRAIN (all policy basis, vet to confirm); MAM-DYSTOCIA no longer fires on bare "straining". Not used: horse, cow, llama, pig cases and 3 small-mass cases (Irish terrier, hound, cat nose).

  Vet-section pass (MSD veterinary Emergency Medicine pages, https://www.msdvetmanual.com/emergency-medicine-and-critical-care/...): heart-rate floor now follows the initial-triage page (dog <60 or >180 bpm, cat <150 or >220 URGENT, cat <120 EMERGENCY; owner-measured pulses are noisy, vet to confirm); new rules ALL-EYE-PENETRATING, ALL-EYE-URGENT, ALL-TRAUMA-MINOR (internal injury can show hours to days later), DC-BITE-NECK-SWELL. The vet index page (`/veterinary-topics`) and sitemap topic file are not readable by our tools: reach pages by their section URL. Still unread: toxicology, digestive, respiratory, cardiovascular, urinary, reproductive, exotic-pet sections.

  Vet-section pass 2 (MSD veterinary Toxicology, Urinary System and Musculoskeletal pages; pages were read by subagents, per-kg doses may be incomplete, levels are inferred, all policy basis, vet to confirm): toxicology rules DOG-MACADAMIA, DC-ONION-GARLIC, DC-MOTHBALL, CAT-ESSENTIAL-OIL (cat/bird/rabbit EMERGENCY), DOG-ESSENTIAL-OIL, DC-RODENTICIDE-NEURO (bromethalin, vitamin D3, strychnine, chloralose, phosphides), DC-THC, DC-TOPICAL-HUMAN (fentanyl, nicotine/tobacco, minoxidil, diclofenac/Voltaren, lidocaine), DC-CLEANER-POD, ALL-SMOKE (fire, soot, Teflon); urinary DOG-URETHRAL, DC-NO-URINE-DAY, DC-URINARY-SICK (urinary signs + vomiting/weakness), CAT-LUTD; orthopedic DC-FRACTURE-OPEN, DC-FRACTURE, DC-JOINT-ACUTE (hot swollen joint with sudden onset; chronic months-long swelling is excluded), DC-STIFF-HOT, CAT-WEAK-NECK. `vet_knowledge.py` gained topics allium, macadamia, essential_oils, cannabis, smoke, urine_block, fracture. Drug classes already in DC-RX-HUMAN/DC-OTC-STIMULANT (antidepressants, heart drugs, ADHD, baclofen, vitamin D, iron) were not duplicated.

  MSD quizzes: each quiz has 3 clinician-recall questions (many equine) and lives on `msdvetmanualquiz.com` (quiz ids come from `quizId` in each quiz page's `__NEXT_DATA__`; answers show after POSTing an answer to `/gcn/startquizdirect/<id>`). They do not describe owner symptoms, so they cannot score the nurse. Four relevant quizzes (food hazards 637, ethylene glycol 699, initial triage 634, exertional heat illness 688 = 12 questions) were used as a fact check: avocado/birds, chocolate (theobromine + caffeine), xylitol hypoglycaemia, antifreeze, "do not induce vomiting" and cat heart rate <120 as shock all agree with the rules; two gaps were found and added (ALL-NOISY-BREATH, DC-GI-PROFUSE). Horse and cattle questions were skipped.

  Full quiz sweep: the quiz site has ~94 quizzes (ids 560-760 on `msdvetmanualquiz.com/gcn/startquizdirect/<id>`, 280 questions, 113 about dogs/cats/small pets; the rest are horse, cattle, poultry and lab topics). All were read and compared with the rules; most test clinician knowledge, 8 owner-level gaps were found and added (policy basis, vet to confirm): DOG-ECLAMPSIA (nursing mother shaking/panting/stiff, EMERGENCY), CAT-FAST-BREATH, DOG-HONK-COUGH, DC-VOMIT-WATER, DC-PUPD-WEIGHT (drinking/peeing/eating more with weight loss), CAT-RAVENOUS-THIN, DOG-NECK-PAIN; `vet_knowledge.py` gained ticks (removal technique), cecotrophy (normal in rabbits/guinea pigs), trauma_watch (48 h), eclampsia. The quizzes are fact checks, not a score of the nurse.
